# D3 异常检测模型与评价协议

## 训练、验证与测试隔离

仅使用20条正常训练运行的180s样本拟合Standardizer和PCA。Standardizer保存训练均值、样本标准差，零方差列的scale置1并记录constant掩码；测试transform不更新参数。采用NumPy SVD实现PCA，无额外sklearn版本依赖。

主成分数仅由训练集累计解释方差达到90%的最小k确定。完整解释方差、比例、累计比例、载荷、中心和特征值保存于model.npz/model_manifest.json；每条测试运行的投影保存为projection数组。

使用10条正常验证运行校准经验控制限，不使用故障验证数据寻优，也不使用测试数据校准。冻结协议预先指定传统阈值统计量99%分位，T²和SPE各99.5%分位，采用higher分位取值。联合报警为T²或SPE超过各自控制限，目标是假设下约1%量级的正常联合误报，实际测试FPR另行报告，不能当保证。有限样本和自相关使其不等价于理论独立样本置信界。

模型文件和控制限先写盘、记录训练/校准run_id与模型哈希，之后程序才首次读取测试处理后数据。测试结果不会触发自动调参。未为了提高故障召回选择列、动作或修改标签。

## 四种基线

设标准化观测为z，P为保留主成分的行向量，λ为对应特征值。

1. **Threshold**：正常训练集逐变量中位数为中心，绝对偏差99%分位为基准宽度，变量分数=绝对偏差/宽度，多变量分数为最大值。验证集校准该最大值的99%控制限。保存逐变量贡献，可由分数>控制限识别单变量越界。标准化中心和宽度可逆变换回原物理单位范围。
2. **PCA联合检测**：投影s=(z−μ)Pᵀ，重构ŝ=sP；联合T²/SPE越界。输出完整投影、解释方差和两个统计量。
3. **Hotelling T²**：Σ sⱼ²/λⱼ，检测主子空间内的异常偏移，经验验证控制限，不硬套iid F分布公式。
4. **SPE**：‖z−μ−sP‖²，检测正常低维子空间之外的残差。

严格用 `score > limit` 判异常，等于界限不报警。小特征值分母有1e−12数值下界；基准宽度有1e−6下界，这些数值规则在测试前确定。

SPE逐变量贡献为重构残差平方；T²贡献使用白化分量反投影后逐变量平方，非负且总和等于T²。联合变量排序为T²贡献/控制限+SPE贡献/控制限，在每条故障运行全部故障后样本上先平均、再跨运行平均，不只统计成功检出的样本。此分解不是唯一归因方式，**贡献大不等于根因，也不证明因果边**。

## 评价定义

每种故障的总体表由20条该故障测试运行与相同20条正常测试运行组成，共40条运行/2800个样本；正常对照在不同故障行重复使用，不能再把各行相加声称额外独立样本。每条故障运行保留故障前正常标签。

报告Accuracy、Precision、Recall、固定类别{0,1}的Macro-F1、FPR和混淆矩阵。零分母按0处理；纯正常表无阳性样本，其Precision/Recall以及包含空阳性类的Macro-F1不宜作检测能力比较，主要看Accuracy和FPR。

延迟=故障启用后首次报警时刻−3600s，以180s采样网格计算。未报警记null，并报告检出运行数；平均延迟只在已检出运行上计算，不能将未检出记成0或通过删运行美化平均值。故障前误报另外计数；本阶段无连续确认窗口，不把偶发报警解释成稳定诊断。

保留全部逐运行指标和seed，以及每个FP/FN时刻的error_cases.csv，报告Recall的跨种子最小/最大/标准差。样本自相关，当前不提供基于逐行独立假设的置信区间。

## 可视化与工况覆盖

`artifacts/d3/detection/experiment.html` 是嵌入Plotly脚本的离线独立HTML，可选择全部80条测试运行及四种检测器，无最佳种子过滤。包含反应釜温度、压力、冷却水出口温度、T²/SPE与阈值控制限比、真实标签与报警时间段，标明故障启用时刻。没有读取RNG、IDV或执行器内部状态作为检测输入。

下一阶段数据基础和本次真实检测能力见 [实验结果](D3_EXPERIMENT_RESULTS.md)；本阶段到此停止，不开发完整因果模型。
