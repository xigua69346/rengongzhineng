# D2 核心运行验收结果

日期：2026-11-14。结论：本阶段仿真适配验收通过，可以进入局部动态因果模型的开发和验证；不等于已证明因果可识别、稳健优化有效或真实工厂可部署。

## 实际环境与证据

Windows 11 x64 / CPython 3.12.14。先在调研环境安装正式 wheel，再新建无 system-site-packages 的 `.venv-d2`，从本地 wheelhouse 离线安装。清洁环境只包含 NumPy、适配包及 pytest 测试依赖，不包含 DoWhy、Dash 或审计源码路径。

- 单元与短集成测试：[tests/test_simulation.py](../../tests/test_simulation.py)。5 项测试函数覆盖多个断言；清洁环境 **5 passed in 1.86s**，pip check 无损坏依赖。
- 长时集成：[scripts/validate_d2.py](../../scripts/validate_d2.py)。25 个独立检查 + 1 个总汇检查，全部通过，真实结果为 [results.json](../../artifacts/d2/results.json)。
- 文件/来源/跨环境验证：[artifact_review.json](../../artifacts/d2/artifact_review.json)。13 组原始数据，全部有限，测量 41 列、控制 12 列、文件哈希一致；安装后的引擎源码逐文件匹配固定 commit 的哈希。
- 原始 CSV/NPZ 和 manifest：`artifacts/d2/<实验名>/`。trajectory.npz 合计 84,059,398 字节；不是占位符或合成演示表。

## 粘滞与控制证据

从第 3600 秒同一完整历史分支，初始已接受目标为 **42.64063644392709%**。每个动作持续 120s，分支运行至 4200s。

|动作|下发命令|第一步已接受目标|积分后实际位置|
|---|---:|---:|---:|
|目标+1百分点|43.64063644%|42.64063644%|41.86677606%|
|目标+5百分点|47.64063644%|47.64063644%|42.86677606%|

位置是动态内部状态，不是命令，也不是物理流量。+1 时位置仍可能趋近旧目标，不能把“目标未变”写成“阀门位置永远完全不动”。+5 第一步只朝新目标移动，不能声称瞬时到位。两条动作轨迹与基线逐秒 RNG 字一致，且都无提前终止。

## 失败与修复记录

1. 初次直接 pip install 本项目打包，以及一次 pip wheel 尝试，构建后出现 **WinError 3**，未得到可安装 wheel。依赖标准临时目录的环境问题未确定到唯一根因；显式设置项目内 TEMP/TMP 后 wheel 成功构建。这不是 C 编译器失败，新的 setuptools 构建不调用原 Meson。
2. 在尚无 wheel/安装失败时继续收集测试出现 **ModuleNotFoundError: causalverse**。原因是未安装包；完成正式 wheel 安装后，原测试通过，未删掉断言。
3. 最终运行验收没有失败项。第一阶段原上游 Meson 安装失败仍是历史事实；本阶段通过独立纯 Python 打包解决部署，不修改原始审计仓库。

没有删除失败样本或修改仿真结果。初次同种子重复运行以逐元素断言核验，之后又在清洁环境独立生成并保存全部三组重复轨迹。最终原始证据中保留正常、不同种子和动作臂数据。脚本遇到已有 results.json 会拒绝覆盖，失败检查保存在 JSON 并以非零状态退出。

## 局限与进入下一阶段的条件

目前最大的技术问题已从“控制会被覆盖/历史不能重现”转为**闭环和部分可观测条件下的因果建模正确性，以及 Python 后端的跨实现数值保真**。本阶段没有运行 Fortran/Rust 差分验证；正常 24h 稳定与故障响应正确不等于逐方程等价证明。

允许开始：局部动态 SCM、时间展开、执行器死区模型、观察量/仿真内部真值分离、独立随机动作的效应估计验证。仍需完成后才可作更强结论：跨后端检查、更多种子和工况、控制退出瞬态/安全边界、长时不同故障动作的外生配对核验。

完整复现命令见 [适配报告](D2_SIMULATOR_ADAPTER_REPORT.md)。不进入 UI 或稳健优化开发，直到动态因果模型及效应实验本身通过验收。
